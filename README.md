# 数玺 · 数据文件可信管理工具
> 规范版本：`v1.3` ｜ 算法套件标识：`SXA1` ｜ 协议定版实现

面向中小企业与科研团队的数据文件可信管理工具——给数据文件办一张「防伪身份证」：登记时算三层指纹存入防篡改账本，之后任何人可一键验真，并能把「借阅」授权的每一次查验都留下回执。

---

## 核心设计与创新

1. **三层指纹登记协议**：
   - **第一层 · 精确指纹（字节级）**：256 KB 分块，双 Merkle 树（SHA-256 + SM3 国密标准），合并域分隔（叶子 `0x00`、内部节点 `0x01`）。
   - **第二层 · 感知指纹（长相级）**：页面灰度（BT.601）→ 32×32 DCT → 取除直流分量外的 63 个交流系数均值计算 64 位 pHash；逐页汉明距离均值 ≤ 8 判定长相未变；文本 3-gram 集合 Jaccard 相似度（阈值 ≥ 0.90）。
   - **第三层 · 语义指纹（事实清单）**：抽取带标签业务字段，实施金额消歧换算、真实日历日期修复、空白压缩、独立 ≥128 位随机盐与 Merkle 路径生成，支持选择性披露证明。
2. **四级分级验真**：
   - **甲级 · 原件未动**（把握基线 99%）
   - **乙级 · 载体变、内容等价**（把握基线 75–90%）
   - **丙级 · 内容自相矛盾**（把握基线 85%，G1 合计复算 / G2 大小写一致）
   - **丁级 · 关键字段被改**（把握基线 95%，精确定位差异字段及新旧值）
   - **待人工复核**（把握基线 ≤ 40%）
3. **哈希链防篡改账本**：
   - JSONL 追加写，每个区块包含上一区块哈希 `prev_hash`。
   - Ed25519 签名验签，RFC 8785 规范 JSON 序列化（载荷内严禁浮点数）。
   - 登记、授权、回执、作废、检查点、密钥公告六类条目闭环。

## 诚实边界明示（Known Boundaries）

- **只能证明「登记之后未被改动」，不能证明「登记时内容本身真实」**。
- **语义层只覆盖带标签字段**，无标签自由文本的改动仅靠文本相似度兜底，长文档小幅改动可能不被检出。
- **扫描路径 OCR 误读可能导致假警报**。
- **云端 Community Cloud 磁盘不持久**（休眠/重启清空属平台特性，靠一键载入恢复演示数据）。

## 环境要求

- **Python**: `>= 3.10`（推荐 Python 3.12）
- **操作系统**: Linux / macOS / Windows
- **系统字体**: `fonts-noto-cjk` 或 `fonts-wqy-microhei`（云端生成中文图像样例必须）

## 两种部署步骤

### 1. 本地一键启动 (推荐)

在项目根目录下执行自带的启动脚本：

```bash
chmod +x run.sh 启动数玺.sh
./run.sh
```

脚本将自动创建/激活虚拟环境，安装 `requirements.txt` 依赖，预先生成确定性演示样例，并启动 Streamlit 实例于 `http://localhost:8501`。

若在桌面环境，可直接双击运行 `./启动数玺.sh`。

### 2. 云端 Streamlit Community Cloud 部署

1. 将仓库推送至 GitHub。
2. 在 [share.streamlit.io](https://share.streamlit.io) 新建应用，指定 Main file path 为 `app.py`。
3. 仓库根目录已包含 `packages.txt`（包含 `fonts-noto-cjk`）及 `requirements.txt`，云端将自动装配依赖环境。
4. 部署后点击侧边栏「一键载入演示数据」即可立即初始化体验。

## 演示走查脚本（约 1 分钟快速体验）

1. **一键载入**：在左侧边栏底部点击「一键载入演示数据」，系统幂等载入《2026年三季度经营报表》、设备采购合同与扫描件。
2. **验真篡改件得丁级**：切换至「验真」页，凭证选择 `SX-0001 · report.txt`，待验文件下拉选中 `report_tampered.txt`，点击「开始验真」：
   - 界面瞬间弹出玫红色「丁级 · 关键字段被改」结论卡与红色「丁级」玺印。
   - 依据清单明确指明 `净利润` 字段由登记值 `4200000` 被篡改为当前值 `5800000`。
3. **深挖证据**：展开「深挖证据 · 三层指纹 / 勾稽 / 报告凭证」，查看精确双根变动对照、语义字段差异表与 G1/G2/G3 勾稽复算。
4. **账本回执与检查点**：切换至「授权与账本」页面，观察顶部全链校验通过、28 块链图流动光效、最新查验回执入账，点击「写入检查点（封印当前链头）」完成锚定封印。
