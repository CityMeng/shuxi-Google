# 数玺（Shuxi）· 数据可信管理工具

面向中小企业与科研团队的数据可信管理工具：以区块链存证与 AI 核验实现数据文件的确权登记、完整性验真与授权留痕，助力数据资产可信流通与价值释放。

- **三层指纹登记协议**：精确层（SHA-256 + 国密 SM3 双哈希 Merkle 树）、感知层（页面 pHash + 文本相似度）、语义层（关键字段加盐 Merkle 树），一次登记、三重存档。
- **四级分级验真**：甲（原件未动）/ 乙（转格式、内容等价）/ 丙（内部勾稽矛盾）/ 丁（关键字段被改并定位），每级附把握程度与可展开的底层证据。
- **授权留痕**：按天数与次数记名授权，验真自动生成签名回执与可复核的验真报告。

本地运行：`bash 启动数玺.sh` 或 `streamlit run app.py`（详见部署说明）。本仓库同时用于 Streamlit Community Cloud 在线演示部署；演示数据不持久化，进入应用后点「载入演示数据」即可体验。

验证状态：协议规范 v1.3；标准测试向量 55/55、场景测试 36/36、界面测试 14/14；308 例盲测标定总准确率 95.13%，篡改类检出率 100%（行业单哈希基线 50.65%）。
